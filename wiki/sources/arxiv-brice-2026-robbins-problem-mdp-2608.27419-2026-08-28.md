## Narrative

Robbins' problem is a full-information variant of the secretary problem: minimize expected rank of the selected candidate among n interviewed sequentially, deciding after each interview without recall. The paper models instances as infinite MDPs, proposes finite-state abstractions for approximation, and highlights simple memory structures sufficient for near-optimal strategies. For 5 ≤ n ≤ 100, better approximations than previously known are provided (exact values only known for n ≤ 4).
