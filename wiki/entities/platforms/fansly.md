## Raw Concept

Entity page for Fansly — OnlyFans alternative with similar feature set (tiered subscriptions, PPV, DMs) plus stronger internal discovery. 20% platform fee. `[Source: supercreator.app/guides/onlyfans-alternatives (retrieved 2026-05-08)]` `[Source: mexc.com/news/867508 (retrieved 2026-05-08)]`

## Narrative

Fansly is a direct OnlyFans competitor offering the same core feature set (subscriptions, PPV, direct messaging, custom content) with **better internal discovery** — creators can be found by browsing users within the platform. Often used as a secondary platform alongside OnlyFans.

### Platform mechanics `[CONFIRMED]`

| Feature | Details |
|---------|---------|
| **Platform fee** | 20% flat (same as OnlyFans) `[Source: mexc.com/news/867508 (retrieved 2026-05-08)]` |
| **Payment processing** | Standard payment processor fees on top of platform fee |
| **NSFW content** | Fully allowed, similar policy to OnlyFans |
| **AI content** | Allowed with disclosure; not AI-native like Fanvue |
| **Internal discovery** | Stronger than OnlyFans — browse-based creator discovery `[Source: supercreator.app/guides/onlyfans-alternatives (retrieved 2026-05-08)]` |
| **Payout speed** | Similar to OnlyFans (5-7 business days) |
| **Creator interface** | Nearly identical to OnlyFans — low learning curve |

### Monetization options `[CONFIRMED]`

1. **Tiered subscriptions** — monthly recurring (similar pricing to OnlyFans, $4.99-$49.99 cap)
2. **Pay-per-view (PPV)** — individual content pieces, custom videos
3. **Tips** — one-time fan payments
4. **Upsell packages** — bundled content offerings via DM
5. **Referral program** — earn commission by referring other creators

### Why creators choose Fansly `[CONFIRMED]`

| Advantage | Description |
|-----------|-------------|
| **Familiarity** | Nearly identical interface to OnlyFans — easy migration |
| **Internal discovery** | Browse and search features help fans find new creators `[Source: supercreator.app/guides/onlyfans-alternatives (retrieved 2026-05-08)]` |
| **More pricing options** | Flexible tier structures, promotional pricing tools |
| **Lower saturation** | Fewer creators than OnlyFans = less competition for visibility |
| **Secondary platform** | Easy backup if OnlyFans account faces issues |

### Comparison: Fansly vs OnlyFans `[CONFIRMED]`

| Factor | Fansly | OnlyFans |
|--------|---------|----------|
| **Platform fee** | 20% flat | 20% flat |
| **Internal discovery** | Yes, browse + search | None |
| **Creator count** | Lower (less saturated) | 4.6M+ |
| **Market dominance** | Secondary position | Dominant |
| **Feature parity** | Near-identical | Reference standard |
| **AI features** | None built-in | None built-in |
| **Best for** | Secondary platform, diversification | Primary platform, traffic source |
