## Narrative

html-anything is a local AI-agent editor that **generates and sandboxes HTML web-design templates** with one-click deploy to platforms like WeChat and X. It lets local LLMs (Claude Code, Codex) act as autonomous design engines rather than ad-hoc HTML emitters.

### SEO-wiki relevance

For this wiki the value is the **client-site build workflow**. Barbershop / dental / local-service landing pages ship faster and more consistently when a local LLM drives a sandboxed editor that previews and deploys, instead of generating raw HTML blind. html-anything is the agentic surface; @entities/tools/awesome-design-md.md supplies the DESIGN.md baseline it enforces; @entities/tools/claude-code-tool-stack.md is the underlying local stack. Together they form the end-to-end local-business site delivery loop referenced in @concepts/website-essentials-local-business.md.

Apache-2.0 clears commercial use — safe for client-facing deliverables.

### Use pattern

1. Drop the vertical's DESIGN.md template (from awesome-design-md) into the project at init.
2. Drive html-anything with Claude Code / Codex to generate the site against that baseline.
3. Sandbox-preview before any deploy; verify schema markup and conversion elements against @concepts/website-essentials-local-business.md.
4. One-click deploy to the target surface once the operator approves.
