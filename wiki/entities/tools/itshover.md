## Narrative

itshover is a suite of **motion-first React icon components** — animated SVG icons designed to be copied, pasted, and customized directly in source. There is no runtime dependency to install: the SVG motion lives in the component code the developer pastes, so it adds zero dependency bloat.

### SEO-wiki relevance

A web-design asset for the wiki's client-site builds. Local-business landing pages (barbershop, dental, salon) benefit from tasteful micro-interactions on service icons, CTAs, and navigation without dragging in a heavy animation library. Because the motion is copy/paste source code, it slots cleanly into the Next.js / shadcn stacks documented in @entities/tools/claude-code-tool-stack.md, and the icon set can be referenced from a vertical's DESIGN.md template in @entities/tools/awesome-design-md.md. See @concepts/website-essentials-local-business.md for where these assets land in a local-business site.

MIT license — unencumbered for commercial client work.

### Use pattern

1. Browse itshover.com, pick the motion icons matching the vertical's aesthetic.
2. Copy the component source directly into the project (no `npm install`).
3. Customize colors / timing inline to match the DESIGN.md baseline.
4. Apply restraint — micro-interactions support conversion; over-animation hurts it.
