## Narrative

Generic on-page SEO basics still apply (title tags, meta descriptions, H1/H2/H3 hierarchy, image alt text, internal linking, URL structure, content length, Core Web Vitals). The local-specific overlay:

1. **Location signals in title tags + H1** — primary location pages should include city + service in the title (e.g. `Mens Haircut & Fade in Davie, FL — [Shop Name]`). Don't keyword-stuff (`Davie Barber Davie Haircut Davie Fade Best Davie`).
2. **Per-location pages** — for multi-shop operators, a dedicated page per location with **unique** content per location (not duplicated with city-name swap). Each location page must have: address + map embed, hours, service list, photos of *that* shop, the team at *that* shop, that shop's GBP review embed, that shop's booking link. See @concepts/website-essentials-local-business.md.
3. **Service pages** — one page per major service (or a single services page with clear sections + anchor links). Each service has: description, price (if disclosed), what to expect, how it's different from adjacent services (e.g. fade vs taper vs scissor cut). FAQ-format Q&A blocks here are GEO/AEO-favored.
4. **Internal linking** — homepage → location pages → service pages → blog/FAQ. A clear hierarchical structure.
5. **No doorway pages** — Google detects and penalizes thin pages targeting different cities with near-duplicate content. If the operator considers building `/davie-fl/`, `/cooper-city/`, `/plantation/`, etc., each must have substantive unique content (or skip — better to have one strong location page than ten thin ones).
6. **Content quality (E-E-A-T)** — Experience, Expertise, Authoritativeness, Trust. For a barbershop: showing real team, real work, real reviews, real years-in-business signals all weigh. AI-generated boilerplate has a cost.
7. **Mobile-first** — Google indexes mobile version primarily. See @concepts/website-essentials-local-business.md.

Tools: Google Search Console (@entities/tools/google-search-console.md) for measuring real-query traffic + technical issues; Semrush (@entities/tools/semrush.md) or Ahrefs (@entities/tools/ahrefs.md) for keyword research + competitor on-page analysis.
