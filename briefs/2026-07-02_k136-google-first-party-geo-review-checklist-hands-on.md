## Target

**hands-on** — apply **Google first-party** AI Search + GBP review guidance to the operator's two-shop stack (no vendor GEO hacks).

## Summary

Search Central June 2026: SEO foundations + non-commodity content + GBP/Merchant feeds; **skip** llms.txt, chunking hacks, inauthentic mentions. GBP Help 2026-06-30: compliant review asks + reply tone.

## Body

### Step 1 — Mythbust purge (Google Search only)

Mark each tactic **keep / drop**:

| Tactic | Verdict |
|--------|---------|
| llms.txt or “AI text files” for Google | **drop** |
| Breaking pages into tiny AI chunks only | **drop** |
| Synonym-stuffed rewrites for AI | **drop** |
| Paid/seeded “mentions” campaigns | **drop** |
| Foundational SEO (crawl, CWV, unique content) | **keep** |
| GBP + structured local business data | **keep** |
| Schema for rich results (not AI-only) | **keep** |

If any vendor tool pushes dropped items, disable those modules (@entities/tools/geo-optimizer-skill.md).

### Step 2 — Non-commodity content spot-check

Pick **3 service pages** (one per top service). For each:

- [ ] Contains **specific** local/experience detail competitors couldn't copy blindly?
- [ ] Would a customer learn something **beyond** generic “7 tips” content?
- [ ] Organized with clear headings for humans (not fan-out keyword spam)?

If all no → rewrite one page using real shop specifics before GEO probe spend.

### Step 4 — GBP review acquisition (first-party)

Per @sources/google-business-profile-help-2026-tips-get-more-reviews-3474122.md:

- [ ] Review link + QR from GBP dashboard active at checkout
- [ ] **No** discounts/rewards tied to reviews
- [ ] **No** sentiment pre-screen before Google link (@briefs/2026-07-01_k135-review-compliance-vendor-audit-hands-on.md)
- [ ] Staff trained: ask **every** happy customer equally

### Step 5 — Reply quality sample

Audit last **10** public replies:

- [ ] No promotional offers in responses
- [ ] Negatives: personalized, timely, offline path offered
- [ ] Not copy-paste identical text on every 5★ review

Fix worst 3 before next review push.

### Step 6 — GSC eligibility

Search Console → confirm pages indexed; check **Search appearance** / generative AI reports if enabled. Pair with @briefs/2026-06-30_k134-ai-citation-vs-click-audit-hands-on.md.

Re-run checklist **quarterly** or after major site/GBP changes.
