SPCX / Anthropic — the short is the listing

Outlier Weekly's SpaceX versus Anthropic thread is a relative-value note. Two names printed near the same number. One is a listed stack (NASDAQ: SPCX). The other is a lab that is not a stock yet.

The letter

The August 24, 2026 issue The Short Is Not the Perp. It Is the Listing. is the pair write-up. Last week's X Article was the comparison. This letter is the instrument: long listed SpaceX, short Anthropic when underwriters create a stock. August is written as a public filing window, not a confirmed IPO. There is no Anthropic ticker on this page because there is no listing yet.

The letter is the primary source. This page does not reprint it. Read the letter for the tape, the calendar, and the cases where the short would not go on.

What the comparison is

SpaceX is Starlink cash, launch, a GPU landlord, Cursor already inside the cap, and a digital-labor product in beta. Anthropic is Claude. Treating those as the same mark is the failure the thread starts from. If the lab is fairly marked near that print, listed SpaceX at that print is the cheap side of the comparison. If SpaceX is fairly marked, the lab is rich. That is a research framing, not a fill.

The live Anthropic print discussed in the letter is a crypto perpetual, not Anthropic's market cap and not a place to size a trillion-dollar short. The short becomes real when a listing creates borrowable stock.
