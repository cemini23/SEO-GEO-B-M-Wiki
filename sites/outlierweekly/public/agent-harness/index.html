Agent harness

The research and writing stack behind Outlier Weekly: Cursor as the editor, DeepSeek and Grok running in parallel as the model lanes, and wiki linting as the maintenance discipline.

What the harness is

Outlier Weekly is researched and written with a small agent stack rather than a single chatbot session. Cursor is the editor where the work happens. DeepSeek and Grok run in parallel as separate model lanes so two independent analyses can be compared before anything goes into a letter. The operator writes the letters, publishes on Substack, and files the working notes in a linted LLM wiki.

Why it matters to the letter

  • Two model lanes disagree more often than one model doubts itself; the letters record both sides.
  • A linted wiki means a claim from an old issue can be checked against the notes instead of trusted from memory.
  • The same harness that researches markets also builds products (Atto, GuruWatcher, the LP bot), so the letters' operator notes are first-person, not secondhand.

The pieces, one by one

  • Cursor — the editor where the work happens: code, research notes, and letter drafts in one place.
  • DeepSeek — one model lane. Used for a first pass over a market or a problem.
  • Grok — a second model lane. Runs the same problem independently so two analyses can be compared.
  • The wiki — an LLM-readable knowledge base. Every useful finding is filed there, not left in chat.
  • The linter — the maintenance check that finds orphaned pages, broken links, and stale claims before they rot the wiki.

How a letter gets written

  1. Pick one market and load its data into Cursor.
  2. Send the same question to DeepSeek and to Grok in parallel.
  3. Compare the two answers; where they disagree, investigate instead of picking a side.
  4. Apply the three-formula system from Methodology.
  5. Write the letter, publish on Substack, and file the working notes into the wiki.
  6. Run the linter; fix whatever it flags.

Why linting matters

A knowledge base that nothing maintains decays: pages drift, links rot, claims go stale, and a month later the notes contradict the letters. The linting discipline in Your LLM Wiki Will Rot Unless You Lint It is what keeps the memory usable — and it is the same reason this hub site ships with a sitemap, a robots file, and an llms.txt: an owned, maintained index instead of a pile of pages.

What this is not

  • Not a product. The harness is the operator's own setup, documented in public. It is not sold and not hosted.
  • Not a promise. Running models in parallel does not remove error; it surfaces disagreement. The letters publish the disagreements too.
  • Not investment advice. The harness is a research tool; its outputs feed commentary, not orders.
